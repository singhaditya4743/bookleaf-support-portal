# BookLeaf Author Support & Communication Portal

A support ticket system for BookLeaf Publishing. Authors raise queries about their books,
and the BookLeaf team resolves them with AI-assisted classification, prioritisation and
draft responses.

## Tech Stack

| Layer     | Technology                                  |
| --------- | ------------------------------------------- |
| Frontend  | Next.js (App Router), TypeScript, Tailwind  |
| Backend   | NestJS, TypeScript, Prisma                  |
| Database  | PostgreSQL (Neon)                           |
| Auth      | JWT + bcrypt, role-based access             |
| Real-time | Socket.io                                   |
| AI        | Gemini (primary), Groq (fallback), keyword rules (last resort) |

## Repository Structure

```
bookleaf-support-portal/
├── backend/    NestJS API
└── frontend/   Next.js app
```
